# static-schedule-kit

공대 일정 추합용 구글시트와 함께 사용할 수 있는 디스코드 알림 봇입니다.

이 레포는 구글시트의 `참여인원저장` 데이터를 읽어와,  
새로 추가된 일정이 있을 때 디스코드 채널로 자동 전송하는 봇 코드를 제공합니다.

## 주요 기능

- 구글시트 `참여인원저장` 시트 읽기
- 새로 추가된 일정 데이터만 감지
- 명령어를 이용한 일정 출력
- 새 일정이 여러 개일 경우 한 번에 묶어서 전송
- 참여 인원을 닉네임 기준으로 표시
- 필요한 경우에만 선택적으로 사용 가능

## 구성

 디스코드 알림 봇 코드

## 사용 대상

- 구글시트에 정리한 일정을 디스코드로 전송하고 싶은 사람

## 사용 방법

### 명령어
- /일정출력 - 이번주 일정을 출력합니다.
- /시트연동 - 구글시트와 연동합니다.
- /출력채널설정 - 일정을 출력할 채널을 설정합니다.
- /설정확인 - 현재 설정을 확인합니다.
- /일정통계 - 참여자들의 참여도를 확인합니다

## 실행 안내

이 레포는 디스코드 봇 이용을 위한 허브입니다.

사용 전에는 아래와 같은 정보가 필요할 수 있습니다.

- 디스코드 채널 ID
- 구글시트 주소 또는 시트 ID

## 디스코드 알림 안내

디스코드 알림 기능은 기본 시트 사용에 필수가 아닙니다.

시트만 단독으로 사용해도 되며,  
디스코드 연동이 필요한 경우에만 별도 봇 코드를 설정해서 사용할 수 있습니다.

## 주의사항

- 이 레포는 디스코드 알림용 코드만 제공합니다.
- 구글시트 템플릿은 별도로 배포됩니다.
- 디스코드 알림 기능은 추가 기능입니다.
- 시트 사본을 사용하는 경우, 각자 자신의 사본에서 데이터를 관리하게 됩니다.
